# Project Finance — учёт финансов проектов для Bitrix24

MVP веб-приложения для ручного учёта доходов и расходов по проектам. Интерфейс подготовлен как самостоятельное приложение, которое может быть встроено в Bitrix24 как внутренний инструмент.

## Возможности

- список проектов и сводная финансовая эффективность;
- доходы и расходы по каждому проекту;
- стандартные статьи расходов: внешние программисты, внутренние программисты, расходы на ИИ, аренда сервера, дивиденды;
- добавление собственных статей доходов и расходов;
- добавление и удаление собственных статей;
- добавление сотрудников к проекту;
- создание, редактирование и удаление финансовых операций;
- поиск по операциям;
- автоматический расчёт дохода, расходов, прибыли и рентабельности;
- сохранение данных в `localStorage`;
- адаптивный интерфейс.

## Формулы

`Прибыль = Доходы − Расходы`

`Рентабельность = Прибыль / Расходы × 100%`

Если расходы равны 0, рентабельность отображается как 0%, чтобы избежать деления на ноль.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Открыть адрес, который выведет Vite (обычно `http://localhost:5173`).

Для production-сборки:

```bash
npm run build
```

## Архитектура

- React + TypeScript + Vite
- Lucide React для иконок
- состояние приложения хранится в React state
- persistence — browser `localStorage`
- бизнес-логика расчётов отделена от представления на уровне функций `totals()` и `money()`

## Bitrix24

В рамках тестового сделан standalone MVP без привязки к конкретному порталу Bitrix24. Это намеренное решение: бизнес-логика и UI не завязаны на конкретный аккаунт/токен, поэтому приложение можно разместить как отдельный веб-интерфейс или адаптировать под iframe/приложение Bitrix24. Интеграцию с REST API Bitrix24 можно добавить следующим слоем без изменения финансовой модели.
