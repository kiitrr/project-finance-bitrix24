# Использование ИИ

ИИ использовался как инструмент разработки, а не как источник готового непроверенного решения.

## Где применялся ИИ

- проектирование структуры MVP и пользовательских сценариев;
- генерация первоначальных React/TypeScript-компонентов;
- подготовка типизированных моделей Project, Category, Transaction и Employee;
- генерация CSS и адаптивной сетки;
- подготовка тестовых данных;
- формирование README и чек-листа проверки.

## Что проверено вручную

1. Доходы суммируются только по операциям типа `income`.
2. Расходы суммируются только по операциям типа `expense`.
3. Прибыль рассчитывается как `income - expense`.
4. Рентабельность рассчитывается как `profit / expense * 100`.
5. При нулевых расходах приложение не выполняет деление на ноль и показывает 0%.
6. Добавление операции немедленно меняет показатели проекта.
7. Редактирование операции заменяет старую запись, не создавая дубль.
8. Удаление операции уменьшает соответствующий итог.
9. Смена типа операции обновляет список доступных статей.
10. Данные сохраняются после перезагрузки страницы через `localStorage`.

## Пример ручной проверки

Для дохода 1 500 000 ₽ и расходов 850 000 ₽:

- прибыль = 650 000 ₽;
- рентабельность = 650 000 / 850 000 × 100 = 76,47%.

В интерфейсе значение округляется до одного знака: 76,5%.
